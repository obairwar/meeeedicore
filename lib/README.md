# Library (`lib/`)

Business logic and shared utilities for the MediCore HMS app.

| File | Purpose |
|------|---------|
| `prisma.ts` | Prisma client singleton |
| `auth.ts` | Authentication helpers / session |
| `queue-service.ts` | Queue management logic |
| `queue-call-next.ts` | Call-next flow + emits |
| `notification-service.ts` | In-app/WhatsApp/email notifications |
| `audit.ts` | Audit logging helpers |
| `utils.ts` | Utility functions (formatters, helpers) |
